## 安装与更新

- 控制面板“插件社区 → 刷新目录”会自动检索 `nhy-plugin` topic。
- 只安装 Release ZIP；校验 manifest、API 版本、平台和 SHA256。
- 没有 Release ZIP 时，允许使用内部 git clone 作为后备。
- 首次安装/迁移由 `config/plugin_bootstrap.json` + `tools/install_bootstrap.py` 完成。
- 本地仓库仍保留在 `dist/plugin_repos/`（已 git tag），后续插件修改请直接在对应 GitHub 仓库进行。
