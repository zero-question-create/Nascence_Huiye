## 待完成：公开发布

当前机器上的 GitHub CLI **未登录**，且没有 `GH_TOKEN`，因此无法通过 API 创建新的 public 仓库。`git push` 只能推送到已存在的仓库。

在有权限的终端执行：

```powershell
# 任选其一
& "F:\Program Files\GitHub CLI\gh.exe" auth login
# 或
$env:GH_TOKEN = "<有 repo 权限的 token>"
powershell -ExecutionPolicy Bypass -File tools\push_plugin_repos.ps1
```

脚本会：

1. 读取本地仓库；
2. 在当前账号下创建 `nhy-plugin-*` public 仓库；
3. 推送 `main` 与 `v1.0.0` tag；
4. 添加 `nhy-plugin` topic；
5. GitHub Actions 在 tag 上构建 Release ZIP + `SHA256SUMS`。

发布完成后，控制面板“插件社区 → 刷新目录”即可检索到这些仓库。首次安装/迁移由 `setup.ps1`/`setup.sh` 的 bootstrap 自动完成。
